## 确认的问题：模板首部头部风格

第 105 行的光标实际在 template，但窗口起点是第 1 行的 HTML 注释。日志三组均将该窗口标为 `region: other`；使用当前 collector 和文件复核：

```text
cursorRegion: template
windowStartRegion: other
actualCollectorRegion: other
headerFirstLine: // [context] reference only, not part of this file
```

原因是 collector 按窗口起点选择 region，文件开头注释不属于任何 SFC block，继而为 Vue 模板前的头部选择 `//`。因此前缀里的 Vue/HTML 上下文注释风格不正确。该样本仍然补出了正确成员，但这属于已确认的组织上下文缺陷，不能因预测碰巧正确而忽略。

本轮以评测和恢复现场为范围，记录该问题，没有更改业务文件或安装中的扩展实现。
